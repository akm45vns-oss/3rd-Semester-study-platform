## 2. Unit Structure Breakdown

### 1. CAP392 — Java Programming (4 Credits)
- **Unit 1**: Introduction to Java, Features, JVM/JRE/JDK, Data Types, Arrays & ArrayList, OOP Fundamentals (Class, Object, Encapsulation)
- **Unit 2**: Methods, Overloading, Constructors, `this` Keyword, Runtime Polymorphism, Dynamic Dispatch
- **Unit 3**: Inheritance Types, `super` Keyword, Abstract Classes, Interfaces, Default Methods
- **Unit 4**: Exception Handling (`try`, `catch`, `finally`, `throw`, `throws`, Custom Exceptions), Multithreading (`Thread`, `Runnable`, Synchronization)
- **Unit 5**: Java Collections Framework (`List`, `Set`, `Map`), Generics, File I/O (`FileInputStream`, `FileReader`, `BufferedReader`)
- **Unit 6**: JDBC Architecture, `Connection`, `Statement`, `PreparedStatement`, `ResultSet`, CRUD Database Operations

### 2. CAP206 — Database Management Systems (3 Credits)
- **Unit 1**: DBMS Architecture, Three-Level ANSI/SPARC, Data Independence, Relational Model, ER Modeling
- **Unit 2**: Relational Algebra (Select, Project, Union, Joins), SQL DDL & DML, Aggregate Functions, Subqueries
- **Unit 3**: Functional Dependencies, Relational Decomposition, Normalization (1NF, 2NF, 3NF, BCNF)
- **Unit 4**: Transaction Processing, ACID Properties, Concurrency Anomalies (Dirty Read, Lost Update, Phantom Read)
- **Unit 5**: Concurrency Control Protocols (Locking, 2PL, Strict 2PL, Timestamp Ordering), Deadlock Handling
- **Unit 6**: Distributed Databases, Replication & Fragmentation, Recovery Techniques (WAL, Checkpointing), Indexing (B-Trees)

### 3. CAP135 — Front End Web Development (3 Credits)
- **Unit 1**: Semantic HTML5, Page Structure, Links, Tables, Semantic Forms & Input Types
- **Unit 2**: HTML5 Multimedia (`<video>`, `<audio>`, `<canvas>`), Web Storage (`localStorage`, `sessionStorage`)
- **Unit 3**: CSS Fundamentals, Selectors, Specificity, Cascade, Color Systems, Typography
- **Unit 4**: CSS Box Model, Margins, Borders, Padding, Positioning (`relative`, `absolute`, `fixed`, `sticky`)
- **Unit 5**: Modern CSS Layouts, Flexbox (Flex Container & Item Properties), CSS Grid, Responsive Design & Media Queries
- **Unit 6**: JavaScript in Browser, DOM Manipulation, Event Handling, Client-side Form Validation, ES6+ Essentials

### 4. CAB213 — Applied AI: Computer Vision & NLP (3 Credits)
- **Unit 1**: Fundamentals of Applied AI, Traditional AI vs Applied AI, Computer Vision Foundations, Color Spaces
- **Unit 2**: Image Filtering, Blur, Edge Detection (Sobel, Canny), Morphological Operations, Feature Extraction
- **Unit 3**: Deep Learning in Vision, CNN Architectures, Object Detection Concepts (YOLO, Faster R-CNN)
- **Unit 4**: Natural Language Processing Basics, Text Preprocessing, Tokenization, Stemming/Lemmatization, Bag of Words, TF-IDF, Word2Vec
- **Unit 5**: Sequence Models & Transformers, RNN, LSTM, Attention Mechanism, BERT & Transformer Encoders
- **Unit 6**: Applied AI Pipelines, Model Evaluation Metrics (Precision, Recall, F1, IoU, BLEU), Real-World Deployment

### 5. CAB114 — Model Optimization (3 Credits)
- **Unit 1**: Machine Learning Lifecycle, Bias-Variance Tradeoff, Generalization Error, Model Diagnostics
- **Unit 2**: Data Preprocessing & Augmentation, Feature Selection, Imbalanced Data Handling, Regularization (L1, L2)
- **Unit 3**: Neural Network Optimization, Activation Functions, Batch Normalization, Dropout, Optimizers (SGD, Adam, RMSprop)
- **Unit 4**: Hyperparameter Optimization, Grid Search, Random Search, Bayesian Optimization, Early Stopping
- **Unit 5**: Model Compression Techniques, Weight Pruning, Quantization (FP32 to INT8), Knowledge Distillation
- **Unit 6**: Edge AI Deployment, ONNX Runtime, TensorRT / TFLite, Inference Latency & Throughput Benchmarking
